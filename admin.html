GitHub settings

Used to save changes back to your repo. Create a fine-grained personal access token scoped to just this one repo, with Contents: Read and write permission — nothing broader. The token is stored only in this browser's local storage and is sent only to api.github.com. Note: "clear browsing data" in most browsers wipes local storage along with the cache, which erases these settings — a plain hard refresh (Ctrl+Shift+R) does not. Consider saving the token itself somewhere durable (like a password manager) so you're not stuck regenerating it.
