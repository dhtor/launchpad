Drag tiles to rearrange, or drag a widget's grip handle to move the whole group. Use the Edit button above to add, remove, or recolor links, or hand-edit data/links.json directly. Give a link a links array instead of a url to make it open a menu of related links. Add a color field (hex, or a palette name e.g. "var(--pal-teal)" — see the swatches defined at the top of css/style.css) to give any link or group its own accent. Add an order field (a number) to a link or sub-link to control where it sorts — lower comes first. Set "wide": true on a link to make its tile span the full width of its widget. If a site's favicon isn't found automatically, add an iconUrl field with the exact image URL to use instead.
